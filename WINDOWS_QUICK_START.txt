WHAT EACH WINDOW DOES:

Backend Window (start-backend.bat)
  - Serves game assets (player photos, backgrounds, etc.)
  - Handles API requests
  - Port: 8080

Frontend Window (start-frontend.bat)
  - Shows the game UI
  - Handles user interaction
  - Port: 5173

Browser
  - Displays the game
  - Connects to both backend and frontend

TROUBLESHOOTING:

Problem: "install-frontend.bat" does nothing
Solution: Try double-clicking it. It should open a command window.

Problem: Backend/Frontend window closes immediately
Solution: It crashed. Look at the error message before it closed.
  (You can run it again or read README_WINDOWS.md for help)

Problem: Browser shows blank page
Solution:
  1. Check backend window is still running
  2. Check frontend window is still running
  3. Try opening http://127.0.0.1:5173 again
  4. Press F12 to see if there are errors

Problem: Port 8080 or 5173 already in use
Solution: Something else is using that port. Kill it or restart your PC.
