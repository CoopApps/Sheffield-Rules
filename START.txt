RUNNING THE GAME:

Three steps (Windows):
  1. Double-click install-frontend.bat (wait for "SUCCESS!")
  2. Double-click start-backend.bat (keep open)
  3. Double-click start-frontend.bat (keep open)
  4. Browser: http://127.0.0.1:5173

Manual (Command Prompt):
  cd "D:\projects\Saturday at Three"

  Terminal 1:
    cd backend
    cargo run

  Terminal 2:
    cd frontend
    "C:\Program Files\nodejs\npm" install
    "C:\Program Files\nodejs\npm" run dev

  Browser:
    http://127.0.0.1:5173
